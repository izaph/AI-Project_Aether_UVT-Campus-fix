Tabele utilizate de plugin-ul UVT Campus Fix
🎫 glpi_tickets
🔑id INT PK
name VARCHAR(255)
content LONGTEXT
🔗itilcategories_id INT FK
🔗locations_id INT FK
🔗users_id_recipient INT FK
status INT (1-6)
urgency INT (1-5)
type INT
date DATETIME
solvedate DATETIME
closedate DATETIME
is_deleted TINYINT
🏷️ glpi_itilcategories
🔑id INT PK
name VARCHAR(255)
completename TEXT
is_incident TINYINT
is_request TINYINT
📍 glpi_locations
🔑id INT PK
name VARCHAR(255)
completename TEXT
🔗locations_id INT FK (parent)
level INT
building VARCHAR(255)
👤 glpi_users
🔑id INT PK
name VARCHAR(255)
realname VARCHAR(255)
firstname VARCHAR(255)
🔗profiles_id INT FK
language VARCHAR(10)
🛡️ glpi_profiles
🔑id INT PK
name VARCHAR(255)

Relații între tabele

glpi_tickets.itilcategories_id → glpi_itilcategories.id (N:1) — fiecare tichet aparține unei categorii
glpi_tickets.locations_id → glpi_locations.id (N:1) — fiecare tichet are o locație
glpi_tickets.users_id_recipient → glpi_users.id (N:1) — fiecare tichet are un solicitant
glpi_users.profiles_id → glpi_profiles.id (N:1) — fiecare utilizator are un rol
glpi_locations.locations_id → glpi_locations.id (auto-referință) — ierarhie clădire → sală
Categorii configurate: IT (id=1), Retea (id=2), Administrativ (id=3) · 35 locații UVT · 5 roluri: Super-Admin, Admin, Technician, Observer, Self-Service
